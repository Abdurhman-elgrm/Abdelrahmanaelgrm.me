# Abdelrahman Elgrm | Personal Portfolio

> A terminal-style personal website showcasing my projects, experience, certificates, and the things I like to build.

**Website:** https://abdelrahmanaelgrmme.vercel.app/

## About

Hi, I'm Abdelrahman, an Electrical & Computer Engineering student at Menofia University and a Fortnite (UEFN) map developer. I spend most of my time on AI, software, data science, and embedded systems.

This site is my portfolio. It is styled like a terminal, with each section presented as a command such as `whoami`, `cat ~/experience.md`, and `ls ~/projects.md`.

- **About me:** who I am and what I'm into

## Run Locally

No dependencies or build tools are needed.

```bash
# Clone the repository
git clone https://github.com/Abdurhman-elgrm/Abdelrahmanaelgrm.me.git
cd Abdelrahmanaelgrm.me

# Option 1: just open index.html in your browser

# Option 2: serve it locally
npx serve .
# or
python -m http.server 8000
```

Then open `http://localhost:8000` (or the port shown in your terminal).
